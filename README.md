# Real-Time Customer Sentiment Analysis App

A simple machine learning-powered web application built with Python and Streamlit that analyzes customer reviews and classifies them as Positive, Negative, or Neutral.

## Features
- Real-time text analysis using NLTK VADER.
- Clean and interactive user interface built with Streamlit.
- Detailed sentiment score breakdown.
